# Historical UI candidate

`rounded-plates.patch` records an earlier experiment and is retained for
reference. Its folder and Search approach has since been incorporated into
`phone-tools/cgprobe.c`, together with a page-control material adjustment.
The user visually confirmed Search, closed folders, open apps, switcher
wallpaper and sleep/wake with the later tested candidate on 2026-10-30.
See the latest `NOTES.md` for the active binary, tested scope, and limitations.
Do not apply this historical patch to current source.
